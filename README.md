# ReWear · יד שנייה בראש שקט

אפליקציית ווב (mobile-first, עברית RTL) לקנייה ומכירה של בגדי יד שנייה עם תשלום בנאמנות (Escrow). דמו: אין שרת, הכול נשמר ב-localStorage.

Vite + React 18 + TypeScript, Tailwind, Zustand, React Router (HashRouter), Framer Motion.

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה ל-dist
npm run preview  # תצוגה של הבנייה
```

פריסה: Vercel, Framework Preset ‏Vite, Build ‏`npm run build`, Output ‏`dist`.
